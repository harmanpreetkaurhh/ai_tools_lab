# ai_tools_lab

AI Tools LAB - Git and GitHub practice.

## Project Description

This project is created as part of the AI Tools Lab. It demonstrates Git and GitHub concepts such as repositories, branches, commits, pushes, and pull requests. It also contains Python utility functions and a bubble sort implementation.

## Usage

### Bubble Sort

```python
from sorting import bubble_sort

numbers = [5, 2, 4, 1]
print(bubble_sort(numbers))
```

Output:

```text
[1, 2, 4, 5]
```
